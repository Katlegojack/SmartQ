# My SmartQ Result Files

I use this folder to store machine-readable outputs from my ML work.

I keep result files in the repository because I want important experiments to be auditable instead of relying only on screenshots or notebook memory.

I currently separate results into:

- `eda/` for Data Understanding outputs;
- `modeling/` for model comparison and tuning outputs;
- `diagnostics/` for statistical/model-diagnostics outputs.

I treat the CSV and JSON files here as evidence of what I actually measured.

I still keep the notebooks and scripts because result files alone do not explain how I produced the numbers.
